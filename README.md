# 漢字よみ道場 仕様書

スマホ・タブレット・PCのブラウザで動く、漢字の読みを4択で学習するWebアプリです。

## 0. 版と実装状況

| 版 | 内容 | 状況 |
|---|---|---|
| v1 | 4択の読みクイズ、漢検4級〜1級 / 難読漢字の切替、苦手リスト、README表示、オフライン対応 | 実装済み |
| v2 | 漢字の詳細ポップアップ（書き順・音読み・訓読み・使用例）、選択肢の並び替えルールの明確化、問題データのCSV化 | 実装済み |

本書のうち **【v2】** と付いた項目は、v2で追加・変更した仕様です。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 形式 | Webアプリ（HTML / CSS / JavaScript、単一ページ） |
| 対応端末 | スマートフォン、タブレット、PC（モダンブラウザ） |
| 外部ライブラリ | なし（書体のみGoogle Fontsを使用。取得できない時は端末の標準書体） |
| データ保存 | ブラウザの localStorage（端末ごと・サーバ送信なし） |
| オフライン | 対応（PWA。一度開いた端末では電波がなくても起動・出題できる） |
| 公開方法 | GitHub Pages（無料の静的サイト公開） |

### ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（【v2】問題データは含まない） |
| `questions.csv` | 【v2】問題データ（7章） |

| `kanjivg/` | 【v2】書き順データ（漢字1字につきSVGファイル1つ。7章）。配布ファイルには含まれないため、7.4の手順で用意する |
| `tools/extract_kanjivg.py` | 【v2】KanjiVGの配布ファイルから必要な書き順SVGだけを取り出すスクリプト（7.4） |
| `README.md` | 本書（アプリ画面の「仕様（README）」から表示） |

`kanjivg/` と `tools/` フォルダ以外は、すべて同じフォルダ（リポジトリの直下）に置きます。

## 2. 出題モード

| モード | 内容 | 収録数 |
|---|---|---|
| 漢字検定 | 4級 / 3級 / 準2級 / 2級 / 準1級 / 1級 を切り替えて出題 | 各級100問 |
| 大人の難読漢字 | 日常で見かける難読語 | 300問 |

- 「級」の選択は漢字検定モードのときだけ表示されます。
- 級の区分はサンプルとしての目安で、日本漢字能力検定協会の公式な配当とは厳密には一致しません。
- 【v2】収録数は `questions.csv` の行数で決まります。ある級の問題が0件の時は、その級のボタンを押せない状態で表示します。

## 3. 画面と操作

### 3.1 設定帯（画面上部）
- **モード切替**：「漢字検定」「大人の難読漢字」
- **級切替**：4級〜1級（6段階）
- **問題数**：5問 / 10問 / 全問
- **はじめる**：現在の設定で新しく出題を開始
- **仕様（README）**：本書を表示
- モードや級を切り替えると、その設定ですぐに出題が始まります。

### 3.2 問題画面
- 出題語を練習帳風のマス目に1文字ずつ表示します。
- 4つの読みから1つを選択します。並び順のルールは3.3を参照。
- **苦手に追加 / 苦手から外す** ボタンで、回答の前でも後でもその語を苦手リストに登録・解除できます。
- 回答後の表示：
  - 正解：マス目に朱色の丸を描くアニメーション
  - 不正解：正解の読みを表示
  - 共通：ふりがな付き表記、意味、「読みを聞く」（音声読み上げ）、「次の問題」
  - 【v2】ふりがな付き表記の漢字を1字ずつタップできるようにし、タップすると漢字の詳細ポップアップを開きます（3.6）。

### 3.3 【v2】選択肢の並び順
- 問題を表示するたびに、正解1つと誤答3つの計4つをランダムに並べ替えます（偏りのないシャッフル方式：Fisher–Yates）。
- 「もう一度」「間違えた問題をもう一度」「苦手だけを復習する」などで同じ問題が再び出た時も、そのつど並べ直します。
- 同じ問題を続けて解き直した時に、正解の位置（1〜4番）が前回と同じにならないようにします。前回の位置はアプリを開いている間だけ覚え、保存はしません。
- 選択肢の左の番号（1〜4）は表示位置の番号で、キーボードの1〜4キーと対応します。

### 3.4 結果画面
- 正解数 / 出題数と、ひとことメッセージ
- 間違えた語の一覧（読み付き）。各行から苦手リストへの追加・解除ができます。
- 【v2】一覧の出題語の漢字もタップでき、詳細ポップアップを開きます。
- 「間違えた問題をもう一度」「同じ設定でもう一度」

### 3.5 苦手な漢字（画面下部）
- 苦手リストの語をチップで表示します。
  - `×数字`：間違えた回数
  - `追加`：手動で登録した語
  - チップの「×」ボタンで個別に削除
- **苦手だけを復習する**：苦手リストの語だけで出題
- **記録を消す**：苦手リストをすべて消去
- **一覧から追加する**：現在のモード・級の全収録語を一覧表示し、語ごとに登録・解除できます。

### 3.6 【v2】漢字の詳細ポップアップ

**開き方**
- 回答後のふりがな付き表記、および結果画面の一覧にある漢字を1字ずつタップ（クリック）すると開きます。
- タップできる漢字には点線の下線を付けて、押せることが分かるようにします。
- ひらがな・カタカナ（送り仮名など）はタップの対象外です。
- 回答前のマス目の漢字はタップできません（読みのヒントになるため）。

**表示内容**

| 項目 | 内容 |
|---|---|
| 見出し | 漢字を大きく表示し、画数を添える |
| 書き順 | 1画ずつ線が描かれるアニメーション。各画の書き始めに画の番号を表示 |
| 音読み | カタカナで表示（例：イ） |
| 訓読み | ひらがなで表示。送り仮名は薄い色で表示（例：なぐさ**める**） |
| 使用例 | 熟語と読みを3〜5件表示（例：慰問（いもん）） |

**書き順の操作**
- **再生**：1画目から最後まで自動で描く（ポップアップを開くと自動で1回再生）
- **1画ずつ**：押すたびに1画進める
- **最初から**：白紙に戻す
- 端末で「視差効果を減らす（アニメーションを減らす）」が有効な時は、アニメーションせず全画を番号付きで表示します。

**その他の操作**
- 出題語に漢字が複数ある時は、「前の字」「次の字」でポップアップを閉じずに切り替えられます。
- 「この字を聞く」で音読み・訓読みを読み上げます。
- 閉じ方：「閉じる」ボタン、ポップアップの外側をタップ、Escキー。

**データがない時**
- `kanji.csv` にその漢字の行がない時は、読み・使用例の欄に「この漢字の情報はまだ登録されていません」と表示します。
- `kanjivg/` にその漢字のSVGがない時は、書き順の欄に「書き順データがありません」と表示し、漢字を大きく表示するだけにします。

## 4. 苦手リストのルール

| きっかけ | 動作 |
|---|---|
| 不正解だった | 間違えた回数 +1（自動でリストに入る） |
| 正解した | 間違えた回数 -1。0になるとリストから外れる |
| 手動で追加した | 正解しても外れない。手動で外すまで残る |
| チップの「×」／「苦手から外す」 | 間違えた回数と手動登録の両方を消す |

## 5. キーボード操作（PC・外付けキーボード）

| キー | 動作 |
|---|---|
| 1〜4 | 選択肢を選ぶ |
| Enter | 次の問題へ |
| Esc | READMEやポップアップを閉じる |
| ← / → | 【v2】ポップアップで前の字 / 次の字 |

## 6. 保存データ（localStorage）

| キー | 内容 |
|---|---|
| `kyomi-cfg` | モード、級、問題数の設定 |
| `kyomi-miss` | 語ごとの間違えた回数 `{ "語": 回数 }` |
| `kyomi-pin` | 手動で登録した語の配列 `[ "語", ... ]` |

- データは端末・ブラウザごとに保存され、他の端末とは共有されません。
- ブラウザのデータを消去すると記録も消えます。
- 苦手リストは出題語で管理しています。CSVで出題語を書き換えると、その語の記録は引き継がれません。CSVから消した語の記録は、苦手リストに表示しません。

## 7. 【v2】データファイルの形式

問題データは `index.html` から切り離し、CSVファイルから読み込みます。ExcelやGoogleスプレッドシートで編集できます。

### 7.1 共通ルール
- 文字コードは **UTF-8**（BOM付き・BOMなしのどちらも可）。Excelでは「CSV UTF-8（コンマ区切り）」で保存します。
- 1行目は見出し行（下記の列名）とし、2行目からデータを書きます。
- 列の順番は見出し行の列名で判断します。列の並びを入れ替えても動きます。
- 値にコンマや改行を含む時は、値全体を `"` で囲みます（Excelで保存すれば自動でそうなります）。
- 空行は無視します。

### 7.2 問題データ `questions.csv`

| 列名 | 必須 | 内容 | 例 |
|---|---|---|---|
| 区分 | ○ | `4級` `3級` `準2級` `2級` `準1級` `1級` `難読` のいずれか | 3級 |
| 出題語 | ○ | 問題として表示する語。全体で重複不可 | 慰める |
| 読み | ○ | 正解の読み（ひらがな） | なぐさめる |
| 誤答1 | ○ | 誤りの選択肢 | いさめる |
| 誤答2 | ○ | 誤りの選択肢 | なだめる |
| 誤答3 | ○ | 誤りの選択肢 | あがめる |
| 意味 | | 回答後に表示する意味 | 心をなごませ、いたわる |

記入例：

```
区分,出題語,読み,誤答1,誤答2,誤答3,意味
3級,慰める,なぐさめる,いさめる,なだめる,あがめる,心をなごませ、いたわる
難読,流石,さすが,りゅうせき,ながれいし,るせき,やはり。評判通り
```

### 7.3 漢字データ `kanji.csv`

| 列名 | 必須 | 内容 | 例 |
|---|---|---|---|
| 漢字 | ○ | 漢字1字。重複不可 | 慰 |
| 画数 | | 総画数（空欄の時は書き順データから数える） | 15 |
| 音読み | | カタカナ。複数ある時は `・` で区切る | イ |
| 訓読み | | ひらがな。送り仮名の前に `-` を入れる。複数ある時は `・` で区切る | なぐさ-める・なぐさ-む |
| 使用例 | | `熟語（読み）` を `・` で区切って並べる | 慰問（いもん）・慰安（いあん）・慰労（いろう） |

### 7.4 書き順データ `kanjivg/`
- KanjiVG（https://kanjivg.tagaini.net/ ）が公開している漢字ごとのSVGファイルを使います。
- ファイル名は、漢字の文字コード（Unicode）を16進数5桁・小文字で表したものです。例：「慰」(U+6170) → `kanjivg/06170.svg`
- 収録語に使われている漢字の分だけ置けば足ります。

**用意する手順**（Python 3 が必要）
1. https://github.com/KanjiVG/kanjivg/releases から、最新版の `kanjivg-日付-main.zip` をダウンロード
2. アプリのフォルダで次を実行（zipは展開しなくてよい）

```
python tools/extract_kanjivg.py ダウンロードしたzipのパス
```

3. `questions.csv` の出題語に使われている漢字のSVGだけが `kanjivg/` に入る。見つからなかった漢字は画面に表示される
4. `questions.csv` に問題を追加した時は、もう一度実行すれば足りない分が追加される

**ライセンス**：KanjiVG は Ulrich Apel 氏による作品で、CC BY-SA 3.0 で公開されています。アプリのポップアップ下部とREADMEに出典を表示します。

### 7.5 読み込み時のチェック
アプリ起動時に読み込み、次のような行はスキップします。スキップした件数と行番号は、画面下部の注記に表示します。

| 内容 | 扱い |
|---|---|
| 必須の列が空 | その行をスキップ |
| 区分が決められた値以外 | その行をスキップ |
| 出題語が既に出ている | 後から出てきた行をスキップ |
| 誤答に正解と同じ読みがある、または誤答どうしが重複 | その行をスキップ |
| `questions.csv` 自体が読み込めない | 「問題データを読み込めませんでした」と表示し、出題しない |

`kanji.csv` が読み込めない時は、問題はそのまま出題し、ポップアップの読み・使用例の欄だけ「情報なし」とします。

## 8. オフライン対応（PWA）

- 初めて開いた時に、`sw.js` がアプリのファイル一式を端末に保存します。保存が終わると画面下部に「オフライン準備完了」と表示されます。
- 以降は電波がなくても、ホーム画面のアイコンから起動して出題・苦手リスト・README表示・読み上げが使えます。
- 【v2】`questions.csv`、`kanji.csv` も最初に保存します。書き順のSVGは、ポップアップで一度表示した漢字の分から保存していきます（すべての漢字を最初に保存すると、初回の読み込みが重くなるため）。
- 読み上げは端末の音声合成を使います。オフラインで読み上げできるかは端末の音声データ次第です。

| 対象 | 取得方法 |
|---|---|
| 画面（index.html）とREADME | ネット優先。つながらない時は保存済みを表示（更新がすぐ届く） |
| 【v2】`questions.csv` / `kanji.csv` | ネット優先。つながらない時は保存済みを使う |
| 【v2】書き順SVG | 保存済み優先。なければ取得して保存 |
| アイコンなど | 保存済み優先 |
| Google Fonts | 保存済み優先、裏で更新 |

### アプリを更新する時
1. `index.html` などを修正してGitHubにアップロード
2. `sw.js` の `VERSION` を `'v1'` → `'v2'` のように上げてアップロード
3. 各端末でアプリを開き直すと、新しい版に切り替わり古い保存データ（キャッシュ）が削除されます

【v2】CSVだけを直した時は `VERSION` を上げなくても、ネットにつながった状態でアプリを開き直せば新しい問題が反映されます。

成績（苦手リスト）はキャッシュとは別に保存しているため、更新しても消えません。

### 手元のPCで動作確認する時
【v2】CSVを読み込むため、`index.html` をファイルのままダブルクリックで開くと動きません。フォルダで簡易サーバを起動して確認します。

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 9. 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成（例：`kanji-yomi`、Public）
2. 「Add file」→「Upload files」で、上記ファイルをすべてドラッグ＆ドロップして「Commit changes」（【v2】`kanjivg` フォルダはフォルダごとドラッグする）
3. 「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `(root)` にして「Save」
4. 1〜2分後に `https://ユーザー名.github.io/kanji-yomi/` で開ける
5. 家族にURLを送り、各自の端末で次の操作をしてもらう
   - Android（Chrome）：「︙」→「ホーム画面に追加」または「アプリをインストール」
   - iPhone / iPad（Safari）：共有ボタン →「ホーム画面に追加」
